# Voces con Derechos

## Descripción

**Voces con Derechos** es una plataforma educativa orientada al aprendizaje sobre los derechos y la dignidad de la mujer.

El proyecto busca utilizar herramientas digitales e interactivas para apoyar el aprendizaje de estudiantes y docentes, promoviendo conocimientos relacionados con los derechos, la igualdad, el respeto y la prevención de la violencia.

Actualmente se encuentra en desarrollo. La primera versión implementada incluye la estructura inicial del backend, la conexión con PostgreSQL y el modelo relacional de la base de datos.

---

## Tecnologías utilizadas

### Backend

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- Npgsql.EntityFrameworkCore.PostgreSQL
- C#

### Base de datos

- PostgreSQL 15
- Docker
- Docker Compose

### Control de versiones

- GitHub
